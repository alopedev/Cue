# Cue

App para iPhone (iOS 27, SwiftUI) para llevar el registro de las series y películas que ves y que te recomienda qué ver según el tiempo que tienes y tu mood.

- Qué se construye: [docs/PRD.md](docs/PRD.md) (v0.2).
- Cómo se construye: [docs/METODOLOGIA.md](docs/METODOLOGIA.md).

- Reglas para los agentes: [CLAUDE.md](CLAUDE.md).

Estado: la base del proyecto está montada (proyecto de Xcode, paquete `CueKit` y comprobaciones automáticas). Lo siguiente es el bloque 1, la biblioteca. El avance se ve en las [PR](https://github.com/alopedev/cue/pulls).
